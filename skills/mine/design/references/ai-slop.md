# AI slop — the tells, and the gate

**AI slop** is the generic look that appears when a system generates UI from defaults
instead of intent. It's instantly recognizable and it's the opposite of the goal. Learn
the tells, then run the gate against the **rendered** artifact (the oracle), not the code.

## The tells

- Purple / violet **gradient hero** (the single most common giveaway).
- Generic **3-column grid of rounded cards**, all identical weight.
- **Centered hero + two CTAs** ("Get started" / "Learn more") with nothing specific.
- **Emoji used as UI icons**.
- Everything the **same size and weight** — no hierarchy, headlines don't carry structure.
- **Decorative gradients / blurred blobs** standing in for real content or imagery.
- **Glassmorphism** everywhere; frosted panels for their own sake.
- Multiple competing accents, or an accent on everything (so nothing stands out).
- **Ad-hoc spacing** — numbers that don't belong to any scale.
- Scattered, unrelated **motion** — things animating because they can.
- Placeholder copy that could describe any product ("Empower your workflow").

## The gate

The artifact ships only when **every** item is true, checked against the rendered output
at its real size(s):

1. **Voice on first contact** — the brand/personality is unmistakable within the first screen.
2. **One signature move** — exactly one bold element; everything else is quiet and doesn't compete.
3. **Hierarchy without color** — structure is readable from type and spacing alone; headlines carry it.
4. **Zero tells** — none of the slop tells above are present.
5. **Every value is a token** — no ad-hoc colors, sizes, or spacings; all trace to the design system.
6. **Real content** — actual text and imagery, not decorative filler.
7. **Legible under stress** — contrast passes at target size; long and localized strings don't break buttons, tabs, or cards.
8. **Purposeful motion** — every animation clarifies cause and effect; nothing is decoration.
9. **Renders at target** — verified at each real viewport/size (web: check 375px mobile too); light and dark if both are claimed.

Any miss → make the **smallest** material, geometry, spacing, contrast, typography, or
copy change that clears it. Re-check against the oracle. Don't rewrite what already works.
