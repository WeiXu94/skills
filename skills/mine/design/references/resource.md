# Resources

Source material this skill draws from — reference implementations, the DESIGN.md
standard, and pre-decoded design systems to steal from.

## The DESIGN.md standard & libraries to steal from

- **design-bites** — https://github.com/educlopez/design-bites
  270+ `DESIGN.md` files auto-extracted from world-class sites (Linear, Stripe, Vercel).
- **awesome-design-md** — https://github.com/voltagent/awesome-design-md
  73+ curated `DESIGN.md` files; explains the 9-section Stitch spec.
- **Geist (Vercel)** — https://vercel.com/design.md
  A production design system published as a single `design.md`; the worked example.

## Reference design skills

- **Anthropic frontend-design** — https://github.com/anthropics/skills/tree/main/skills/frontend-design
  Studio methodology: hero-is-a-thesis, spend boldness in one place, self-critique vs AI defaults.
- **Anthropic canvas-design** — https://github.com/anthropics/skills/blob/main/skills/canvas-design/SKILL.md
  Static art (.png/.pdf): name the aesthetic, ~90% visual / 10% text, museum-quality craft.
- **Waza ui (tw93)** — https://github.com/tw93/Waza/blob/main/skills/ui/SKILL.md
  Evidence-first polish: rendered output is the oracle, minimal intervention, anti-slop gate.
- **baoyu-design (JimLiu)** — https://github.com/JimLiu/baoyu-design
  Packages Claude's design system as a portable skill; self-contained HTML, decks, import/export.
